# v1.5.0 发布说明

MarukoBox 2026（小丸工具箱）1.5.0 —— 输出命名自定义、全新图标、更顺手的拖放与更新源。

## 新功能
- **输出文件命名规则**：可在设置中自定义默认输出文件名。预设组合包括「原名」「原名+时间（默认）」「原名+编码格式」「原名+编码格式+分辨率」以及「+容器」等，自动避免覆盖源文件。
- **全新应用图标**：替换为你提供的新图标（透明背景）。运行时标题栏/任务栏、安装包、开始菜单与桌面快捷方式现已一致显示新图标。
- **视频页拖放升级**：左侧整栏均可拖入文件；拖入时显示全页高斯模糊遮罩，中央提示「松开即可添加文件」。
- **更新源更名 GitHub / CN**：CN 源一次切换同时驱动**软件更新**（Gitee）与 **ffmpeg 依赖更新**（兰州大学镜像），两处生效，不再只是改名。
- **窗口最小尺寸 + 响应式三列**：设定窗口最小尺寸；缩小窗口时左、中、右三栏（含左右侧栏）同步压缩。

## 优化与修复
- 移除视频页 GPU 编码（CQP/CRF）冗余提示文字，界面更干净。
- **安装器升级逻辑**：安装新版时自动静默卸载已安装的旧版本（保留 `%LOCALAPPDATA%\MarukoBox` 下的用户配置与数据），旧 exe 移除后图标缓存自然失效，新图标即时可见。

## 已知限制
- 抽取 / 抽帧类任务暂未纳入命名规则（受 ffmpeg 序列帧占位符约束）。
- 「原名+时间」默认格式为 `原名_yyyyMMdd_HHmmss`。

## 下载
`MarukoBoxSetup-Inno_1.5.0.exe`（当前用户安装，无需 UAC），内置 ffmpeg 7.1.1-5。
