# MarukoBox v1.5.0

> 输出命名自定义 · 全新图标 · 更顺手的拖放与更新源

## 新功能
- **输出命名规则**：预设组合（原名 / +时间[默认] / +编码格式 / +分辨率 / +容器），自动防覆盖源文件。
- **全新图标**：替换透明背景新图标，运行时、安装包与快捷方式显示一致。
- **拖放升级**：视频页整栏可拖入文件，拖入时全页高斯模糊遮罩 +「松开即可添加文件」。
- **更新源 GitHub / CN**：切到 CN 同时驱动软件更新（Gitee）与 ffmpeg 更新（兰大镜像）。
- **窗口最小尺寸 + 三列响应式**：缩窗时左、中、右三栏同步压缩。

## 优化
- 移除视频页 GPU 编码（CQP/CRF）冗余提示；安装器升级时自动静默卸载旧版（保留用户配置）。
