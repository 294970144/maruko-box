# MarukoBox v1.7.2

> 距离上次公开发布版 v1.6.0，本次带来全新的「裁剪」页、新增「打开输出文件夹」、一批稳定性修复，以及更新机制加固。

> 说明：v1.7.0 / v1.7.1 为内部版本，未对外发布，其变更随本次 v1.7.2 一同发布。

## 新增

### 裁剪页（全新功能）

- **双端点时间轴**：载入视频后显示预览画面与时间轴，**拖动左右两个圆点**即可选定开始与结束时间；拖动过程中画面实时跟到对应帧。
- **三种定点方式**：拖动圆点 / 「设为当前位置」按钮 / ±0.1s 与 ±1s 微调。
- **首尾帧缩略图**：起点与终点各显示一张，用于确认选段边界（松手后刷新，避免拖动中逐帧抽图拖垮界面）。
- **两种剪切模式**：
  - **快速剪切（默认）**：`-c copy` 秒级完成、画质零损失，画面 / 音轨 / 字幕全部原样保留。实测起点精确到帧，尾部可能多带极少量画面（合成测试片约 0.07 秒）。
  - **精确剪切**：重新编码画面，起止精确到帧，可选编码器（自动优先 GPU / H.264 NVENC / H.265 NVENC / H.264 CPU）与画质档位。此模式只保留画面与音轨。
- **播放器联动**：播放到终点自动暂停；指针在选段外时点播放会先跳到起点。

### 打开输出文件夹

- 视频 / 音频 / 字幕 / 抽取 / 图片 / 封装 / 裁剪 七个工具页，以及设置页的「默认输出目录」，均新增「打开」按钮。
  - 该工具**成功产出过文件**时，点击直接定位并选中那个文件（`explorer /select`）；
  - 尚无产出记录时，打开输出目录（未指定输出目录则回退到源文件所在目录）。

## 修复

- **修复裁剪页无法打开**：裁剪页因 Slider 范围声明顺序不当，在页面构造阶段抛出异常导致整页无法打开；现已修正，裁剪功能可正常进入。
- **多 GPU 设备号只对 NVIDIA 生效**：此前 `-gpu` 参数会被追加给 AMD AMF 与 Intel QSV 编码器，而它们不认这个参数，填了设备号的用户每次编码都会失败。现在只在 NVENC 下追加。
- **音频转码的失败原因不再被覆盖**：音频页转码出错时，finally 会无条件把状态文本改写成「转码结束」，具体错误原因被吞掉（视频页此前已修复，音频页漏了，本次补齐）。
- **手动 ffmpeg 路径的生效条件已说明**：内置 ffmpeg 存在时，设置页手动填写的路径不会生效（优先级为「内置 → 手动 → PATH」）。现在设置页会明确提示这一点，不再是「设置了没反应」。
- **构建脚本不再把编译失败当成成功**：Inno Setup 编译失败时退出码未传出一键构建脚本，dist 里没有新安装包却会打印「完成」。现已修正，并额外按版本号核对产物是否真的生成。

## 更新机制加固

- **自动更新增加完整性校验**：下载应用与 ffmpeg 后，用 SHA-256 比对随包发布的校验值，校验不通过的安装包不会被执行，避免下载被截断或镜像源内容漂移（真正的防篡改仍依赖安装包签名）。
- **更新确认弹窗异常时不再静默放行**：设置页的「确认更新应用 / 确认更新 ffmpeg」对话框若发生异常，此前会被当作「用户已同意」继续更新，存在误更新风险；现改为「异常即中止」并记日志。
- **裁剪页临时缩略图会在退出时清理**：此前抽帧生成的临时图留在系统临时目录，现随裁剪页关闭统一回收，并清理较早的历史缩略图。

## 优化

- 精简软件内文案，去除冗余与重复表述：
  - 裁剪页副标题去掉与「快速剪切」开关重复的说明；
  - 字幕页副标题合并为「抽取 / 嵌入字幕流，或在 srt·ass·vtt 间转换」；
  - 设置页「保持习惯」「用户级别」两条说明缩短、去掉与功能本身重复的字眼。

## 说明

- 预览使用系统解码器，个别编码放不出来时会降级为「无预览」模式并给出提示，时间轴与裁剪仍可正常使用。
- 输出默认落在源文件同目录，按设置里的「输出文件命名规则」命名；若规则会生成与源文件同名的路径，自动追加 `_trim` 等后缀，避免覆盖原片。
