# v1.4.1 发布说明

热修版：修复 1.4.0 审查发现的质量档失效（P0）及多项安全/稳定性问题。

## 主要修复
- **质量四档失效（P0）**：低/中/高/非常高此前不生效（GPU 路径未切换到 CQP 模式，四档输出体积相同）。现已同步切换编码模式，四档真正拉开差距。
- **「编码完成后」生效**：退出 / 关机 / 休眠真正可用，执行前弹可取消确认窗，且仅全部编码成功时触发。
- **失败原因不再被覆盖**：编码出错时保留失败原因，不再被「全部完成」覆盖。
- **关于页版本号**改为读取程序集版本。

## 安全与稳定性
- 更新包下载移至用户目录（消除权限漏洞），版本号加白名单校验。
- 自定义 ffmpeg 参数拦截换行、`|`、`&` 等注入字符。
- 日志迁移至 `%LOCALAPPDATA%\MarukoBox\logs\`，路径脱敏、自动轮转。
- GPU 检测并发化并缓存，启动更快；探测取消时终止 ffmpeg 子进程。

## 许可证与更名
- 主程序协议由 MIT 改为 **GPL-3.0**（内置 ffmpeg 为 GPL，见 THIRD-PARTY-NOTICES）。
- 产品更名为 **MarukoBox 2026**（小丸工具箱）。
