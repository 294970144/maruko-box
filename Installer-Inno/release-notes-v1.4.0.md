# v1.4.0 发布说明

## 界面

### 1. 视频页「输出文件夹」移至右侧
- 从中栏参数区移到「输出与进度」卡片顶部，编码前顺手确认输出位置，布局更紧凑。

### 2. 「普通」级新增质量四档
- 按恒定质量给出 低 / 中 / 高（推荐）/ 非常高 四档（CRF/CQP 30/26/22/18），CPU 与 GPU 编码统一走同一档。
- 仅普通级别显示；高级及以上保留完整码率控制（VBR/CBR/CQP/2-Pass + 码率三件套）。

### 3. 「保持习惯」
- 设置页新增开关（默认开启，即时生效）：退出时记住视频页全部编码设置（编码器、质量、分辨率、容器、音轨字幕、输出目录等），下次打开自动恢复，与上次完全一致。
- 关闭后每次启动回到默认参数。

### 4. 全新应用图标
- 现代化「丸」字图标（多尺寸 ico），标题栏与安装包同步更新。

## 文档

- README 新增界面预览（浅色 / 深色 × 视频页 / 设置页）与应用图标。

## 安装包

- 版本 1.4.0，文件版本（FileVersion）1.4.0.0。
