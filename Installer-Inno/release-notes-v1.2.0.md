# 小丸工具箱 2026 v1.2.0

本版聚焦「更新机制重构 + 用户分级 + 安装包元数据修复」。

## 新功能与改进

### 1. 检查更新 / 检查依赖职责分离

- **检查更新**：只检查软件自身更新（GitHub `294970144/maruko-box`），有新版时弹窗确认 → 下载安装包 → 启动安装程序并退出应用
- **检查依赖**：体检 ffmpeg / ffprobe / 内置版本 / GPU 编码能力，并检查内置 ffmpeg 新版
- 设置页「当前版本」显示软件版本；「硬件能力」卡新增「内置 ffmpeg」行，点「重新检测」一并刷新
- 移除「更新渠道」下拉（软件与 ffmpeg 更新统一走 GitHub）

### 2. NVENC API 13.1 门槛

- jellyfin-ffmpeg **8.x** 起 NVENC 基于 Video Codec SDK 13.1 编译，要求 NVIDIA Windows 驱动 **≥610**（NVENC API ≥13.1）
- 检查依赖发现 8.x 新版时：N 卡驱动 ≥610 才提示更新；驱动过旧（NVENC API <13.1）自动拦截并说明原因，避免升级后 NVENC 硬件编码失效
- **AMD AMF**：官方声明向后兼容所有历史驱动版本，无同类硬门槛，不做限制
- 修正驱动 → API 映射表（13.0 从 570 起、12.2 从 560 起、12.1 从 530 起，此前 13.0 误标为 590）

### 3. 用户三级分级

- 设置页新增「用户级别」下拉：**默认（小白）/ 高手 / 程序员**，重启生效
- **默认**：只显示常用功能（文件队列、精简编码器「自动/NVENC/x264」、质量、分辨率、输出）
- **高手**：额外显示码率控制、目标码率/缓冲、Preset/Profile/Tune、音轨/字幕选项、ffmpeg 路径、多 GPU 序号、编码器全集
- **程序员**：显示全部（含自定义 ffmpeg 参数），即完整界面

### 4. 安装包文件版本修复

- 安装程序文件属性「文件版本」由 `0.0.0.0` 修正为 `1.2.0.0`（新增 `VersionInfoVersion` 指令）

## 技术细节

- ffmpeg 更新查询改为取 GitHub 全部 release 中的**最高版本（含 prerelease）**——jellyfin-ffmpeg 8.x 系列在 GitHub 标为 prerelease，`/releases/latest` 只返回 7.1.4-3 稳定版会漏掉 8.x，导致 NVENC 门槛形同虚设
- 修复版本比较方向错误（此前会选到最旧版本，现已加注释防回归）
