# MarukoBox v1.8.0

> 新增「打开输出文件夹」一键定位结果，并精简软件内文案

## 新增

- **打开输出文件夹**：视频 / 音频 / 字幕 / 抽取 / 图片 / 封装 / 裁剪七个工具页，以及设置页的「默认输出目录」，均新增「打开」按钮。
  - 该工具**成功产出过文件**时，点击直接定位并选中那个文件（`explorer /select`）；
  - 尚无产出记录时，打开输出目录（未指定输出目录则回退到源文件所在目录）。

## 优化

- 精简软件内文案，去除冗余与重复表述：
  - 裁剪页副标题去掉与「快速剪切」开关重复的说明；
  - 字幕页副标题合并为「抽取 / 嵌入字幕流，或在 srt·ass·vtt 间转换」；
  - 设置页「保持习惯」「用户级别」两条说明缩短、去掉与功能本身重复的字眼。

## 说明

- 本次为功能增量（新增按钮）+ 文案打磨，无破坏性变更；按版本规则从 1.7.1 升至 1.8.0。
- 输出默认落在源文件同目录，按设置里的「输出文件命名规则」命名；若规则会生成与源文件同名的路径，自动追加 `_trim` 等后缀，避免覆盖原片。
