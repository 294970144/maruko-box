# MarukoBox v1.8.0

> v1.8.0 是一次 **MINOR** 级更新：在 1.7.4 基础上全面重构「设置」界面（普通 / 高级 / 专家三套模式），落地设置 UI 优化方案的 P0 + P1 项，并修复自 1.7.4 审查报告暴露的 25 项问题（含一处启动崩溃 P0）。所有改动均为非破坏性，配置结构保持兼容。建议所有 1.7.x 用户升级。

## 设置界面全面优化（普通 / 高级 / 专家模式）

### P0 核心修复
- **硬件能力模块语义拆分**：顶部检测横幅仅保留核心结论并支持折叠，详细参数收纳至下方卡片；「版本信息」纯文本与「编码能力支持」的对勾/叉号状态彻底分离，消除信息冗余与配置误判。
- **保存配置按钮悬浮固定**：按钮固定页面右下角、滚动时始终可见；修改任意设置后出现「未保存」红点提示，保存成功后消失。
- **四级统一状态体系**：成功（绿）/ 警告（黄）/ 错误（红）/ 信息（蓝）统一应用于横幅、提示条、表单校验（如路径无效标红、更新源超时显示黄色警告）。
- **自定义 ffmpeg 路径状态与校验**：使用内置 ffmpeg 时输入框置灰禁用并标注版本；启用自定义路径时激活并实时校验文件有效性，无效时标红并提示回退规则与常驻说明。
- **多 GPU 设备序号校验与引导**：限制仅输入数字、增加上下限校验、超限即时标红；新增「查看设备列表」按钮快速选择对应序号。

### P1 体验优化
- 设置按「系统与更新 / 编码核心配置 / 界面与行为」三大区块分组，统一分组标题样式。
- 「⚠️ 重启后生效」图标 + Toast 提示；「保持习惯」增加「即时生效」标签，与重启项明确区分。
- 用户级别命名统一为「普通 / 高级 / 专家」；默认输出目录说明改为占位符、空路径禁用「打开」按钮；删除底部冗余检测文字。
- 左侧导航在「工具」与「设置」间增加分隔线分为功能 / 系统两组；补全控件 hover / 聚焦 / 禁用状态；标题旁「?」帮助图标轻量化说明文字。

## 缺陷修复（25 项，含 1 项 P0 启动崩溃）
- **[P0] 启动崩溃**：`InfoBadge` 误用不存在的 `AttentionDotBadgeStyle`（应为内置 `AttentionDotInfoBadgeStyle`），部分环境下启动即崩（XamlParseException 0xc000027b）。
- **更新模块**：安装加互斥锁避免并发覆盖；下载校验缺失时给出明确警告；元数据与大文件下载拆分两个 HttpClient，避免大文件被缓冲上限截断。
- **裁剪页**：离开页面时正确暂停 / 释放播放器；FileSavePicker 扩展名缺省为 `.mp4`；载入并发取消保护。
- **编码服务**：`-ss` 置于 `-i` 前、裁剪时长用 `-t`；`scale_cuda` 仅当显卡支持 CUDA 解码与缩放时启用；NVENC 质量参数改为 `-preset p5 -rc vbr -cq {q} -b:v 0`。
- **会话 / 退出**：会话恢复正确回写 GPU 设备；退出统一走 `App.Shutdown()`，避免 unpackaged 下进程残留。
- **其他**：x:Load 元素补 `x:Name`；Harness 工程依赖通配纳入 Models / Services 并加 `MARUKO_HARNESS` 隔离；移除无用 WinApp 包；配置保存异常改为显式记录；输出路径批处理去重。

## 说明
- 用户数据（`config.json` / `session.json`）位于 `%LOCALAPPDATA%\MarukoBox`，安装 / 覆盖不受影响。
- 覆盖安装会自动静默卸载旧版并清掉已移除的旧文件；卸载默认保留个人数据，可选一并清除。
