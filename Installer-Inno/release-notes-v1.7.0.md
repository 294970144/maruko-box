# MarukoBox v1.7.0

> 新增「裁剪」页：预览画面 + 双端点时间轴，拖动两个圆点选起止时间

## 新增
- **裁剪页**（导航「视频」下方）：载入视频后显示预览画面与时间轴，**拖动时间轴左右两个圆点**即可选定开始与结束时间。
- **三种定点方式**：拖动圆点 / 「设为当前位置」按钮 / ±0.1s 与 ±1s 微调。拖动过程中画面实时跟到对应帧。
- **首尾帧缩略图**：起点与终点各显示一张缩略图，用于确认选段边界。缩略图在松手后刷新——拖动过程中逐帧抽会把界面拖垮。
- **两种剪切模式**：
  - **快速剪切（默认）**：`-c copy` 直接拷贝码流，秒级完成、画质零损失，画面 / 音轨 / 字幕全部原样保留。实测起点精确到帧，尾部可能多带极少量画面（合成测试片约 0.07 秒）。
  - **精确剪切**：重新编码画面，起止都精确到帧，可选编码器（自动优先 GPU / H.264 NVENC / H.265 NVENC / H.264 CPU）与画质档位。此模式只保留画面与音轨。
- **播放器联动**：播放到终点自动暂停；指针在选段外时点播放会先跳到起点，不会「点了播放听到的却是段外内容」。

## 说明
- 预览使用系统解码器，个别编码放不出来时会降级为「无预览」模式并给出提示，时间轴与裁剪仍可正常使用。
- 快速剪切为默认模式：实测两种模式的起点都是帧级精确的，快速模式唯一的代价是尾部可能多带一点画面且不能改画质，对「剪一刀」的场景不值得为此等一次重编码。
- 输出默认落在源文件同目录，按设置里的「输出文件命名规则」命名；若规则会生成与源文件同名的路径，自动改为追加 `_trim` 后缀，避免覆盖原片。
