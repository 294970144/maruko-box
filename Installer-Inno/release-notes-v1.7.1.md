# MarukoBox v1.7.1

> 新增「裁剪」页（预览画面 + 双端点时间轴），并修复代码审查发现的一批问题

> 说明：v1.7.0 仅构建过本地安装包、未公开发布，其裁剪功能随本版本一同发布。

## 新增：裁剪页

- **双端点时间轴**：载入视频后显示预览画面与时间轴，**拖动左右两个圆点**即可选定开始与结束时间；拖动过程中画面实时跟到对应帧。
- **三种定点方式**：拖动圆点 / 「设为当前位置」按钮 / ±0.1s 与 ±1s 微调。
- **首尾帧缩略图**：起点与终点各显示一张，用于确认选段边界（松手后刷新，避免拖动中逐帧抽图拖垮界面）。
- **两种剪切模式**：
  - **快速剪切（默认）**：`-c copy` 秒级完成、画质零损失，画面 / 音轨 / 字幕全部原样保留。实测起点精确到帧，尾部可能多带极少量画面（合成测试片约 0.07 秒）。
  - **精确剪切**：重新编码画面，起止精确到帧，可选编码器（自动优先 GPU / H.264 NVENC / H.265 NVENC / H.264 CPU）与画质档位。此模式只保留画面与音轨。
- **播放器联动**：播放到终点自动暂停；指针在选段外时点播放会先跳到起点。

## 修复

- **多 GPU 设备号只对 NVIDIA 生效**：此前 `-gpu` 参数会被追加给 AMD AMF 与 Intel QSV 编码器，而它们不认这个参数，填了设备号的用户每次编码都会失败。现在只在 NVENC 下追加。
- **音频转码的失败原因不再被覆盖**：音频页转码出错时，finally 会无条件把状态文本改写成「转码结束」，具体错误原因被吞掉（视频页此前已修复，音频页漏了，本次补齐）。
- **手动 ffmpeg 路径的生效条件已说明**：内置 ffmpeg 存在时，设置页手动填写的路径不会生效（优先级为「内置 → 手动 → PATH」）。现在设置页会明确提示这一点，不再是「设置了没反应」。
- **构建脚本不再把编译失败当成成功**：Inno Setup 编译失败时退出码未传出一键构建脚本，dist 里没有新安装包却会打印「完成」。现已修正，并额外按版本号核对产物是否真的生成。

## 说明

- 预览使用系统解码器，个别编码放不出来时会降级为「无预览」模式并给出提示，时间轴与裁剪仍可正常使用。
- 输出默认落在源文件同目录，按设置里的「输出文件命名规则」命名；若规则会生成与源文件同名的路径，自动追加 `_trim` 后缀，避免覆盖原片。
