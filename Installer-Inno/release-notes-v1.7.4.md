# MarukoBox v1.7.4

> 1.7.4 是自 v1.7.2 以来的累积版本，包含原本计划为 **1.7.3**（未单独发布安装包）的修复与改进，以及 **1.7.4** 自身的裁剪页 UI 改进（均为 PATCH 级）。建议所有 1.7.x 用户直接升级到本版本。

## 1.7.3 部分（未单独发布，合并于此）

### 修复

- **裁剪页「打开」按钮与「另存为」重叠**：输出行网格缺少第三列定义，WinUI 将超出范围的列静默对齐到最后一列，使两个按钮叠在一起。已补齐列定义，两者正确分列。
- **「打开输出文件夹」无输出时仍可点击**：之前载入视频但尚未裁剪时该按钮仍可点，易触发无效操作。现仅在存在裁剪产物时启用，无输出视频时自动禁用。

### 改进

- **裁剪参数纳入会话记忆**：裁剪页的「快速/精确」「恒定质量值」「编码器」现在随「保持习惯」自动记忆与恢复（质量值钳制在合法范围 14–32），不再每次打开重置。
- **裁剪预览区响应式三联布局**：竖屏 / 方形视频预览两侧的大面积空白现在用来放置「起点帧 ｜ 当前画面 ｜ 终点帧」三联画面；横屏视频两侧余量趋近于零时自动回落为下方两列，按视频实际余量切换而非简单按窗口宽度。

## 1.7.4 部分

### 改进

- **裁剪页播放控制改为图标**：播放/暂停、跳到起点、跳到终点由文字按钮改为 `SymbolIcon` 图标 + 悬停提示，界面更紧凑。
- **起止预览帧画面居中且放大**：「起点帧 / 终点帧」画面改为水平居中对齐，缩略图高度由 150 提升至 170，侧位显示更饱满。
- **空格键固定为播放/暂停**：在裁剪页按空格键固定触发播放/暂停，已规避输入框/按钮焦点与长按自动重复导致的误触发。

## 说明

- 用户数据（`config.json` / `session.json`）位于 `%LOCALAPPDATA%\MarukoBox`，安装/覆盖不受影响。
- 覆盖安装会自动静默卸载旧版并清掉已移除的旧文件。
