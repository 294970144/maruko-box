# v1.3.0 发布说明

## 新特性

### 1. ffmpeg 更新按本机驱动兼容性推荐
- 「检查依赖」不再盲目推送远端最高版本，而是拉取全部 release 后按本机驱动兼容性过滤（jellyfin-ffmpeg 8.x 需 NVIDIA 驱动 ≥610 / NVENC API 13.1），在兼容版本中取最高者推荐。
- 驱动过旧时明确告知拦截原因，而不是给出装完 NVENC 就坏的版本。

### 2. 「专家」可安装任意 ffmpeg 版本
- 用户级别「专家」在设置页新增「内置 ffmpeg 版本列表」：点过「检查依赖」或「刷新版本列表」后，列出 GitHub 上全部 jellyfin-ffmpeg release（版本号 / 发布日期 / 包大小 / prerelease 标记 / 兼容性标注）。
- 每行可单独「安装此版本」，**绕过驱动兼容性门槛强制安装**（不兼容时弹窗二次确认并明示后果）。

### 3. 用户级别改名：普通 / 高级 / 专家
- 原「默认 / 高级 / 程序员」三级更名，存储代码不变；旧配置文件与新名称自动互相兼容，升级无感。

### 4. 保存配置后可选立即重启
- 主题或用户级别有改动时，保存后弹「需要重启」对话框，一键重启应用；未改这两项时静默保存不再打扰。

## 变更

### 5. 移除「编码完成后」设置项
- 设置 → 界面与行为 中的「编码完成后」下拉移除（配置字段一并清理；旧配置文件中的残留字段自动忽略）。

### 6. 导航页顺序调整
- 主导航重排为：视频 → 音频 → 封装 → 字幕 → 抽取 → 图片 → 工具 → 设置 → 关于。

## 安装包

- 版本号 1.3.0，文件版本（FileProperty）同步为 1.3.0.0。
