# MarukoBox v1.6.0

> 所有工具页支持直接拖入文件，并按处理场景限定可选格式

## 新增
- **拖拽添加文件**：音频 / 抽取 / 图片 / 封装 / 字幕五个页面的「文件添加」卡片均支持直接拖入文件（此前只有视频页支持）。拖入时卡片描边高亮，松手即添加。
- **文件格式限定**：上述页面的文件选择器与拖放共用同一套白名单，不再允许塞入 ffmpeg 处理不了的格式；不符合的文件会被忽略，并提示忽略数量与可用范围。
- **封装页自动分流**：拖入的文件按扩展名自动归入视频 / 音频 / 字幕轨，无需先点击对应的「+ 添加」按钮。
- **图片页分区限定**：抽帧卡只收视频、转码卡只收图片，同一页两个功能区互不串档。
- **字幕页按类填充**：嵌入区同时接受视频与字幕，视频填入视频框、字幕填入字幕框。

## 说明
- 抽取 / 图片 / 字幕这类「一次只处理一个文件」的区域，一次拖入多个文件时只取第一个，其余计为忽略并给出提示。
